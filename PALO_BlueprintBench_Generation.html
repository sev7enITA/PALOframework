Serving configurations

All calls use cloud inference through OpenRouter. Configuration cards distinguish original serial MCP access from supplementary batch access. No local inference, browser chat or model-assisted reviewer output is included in this comparison. Each model and pinned provider is a distinct configuration. Full source text is supplied directly; no RAG, embeddings or retrieval are used. Observed tokens are recorded per request and differ from the advertised context limit.

Assessment boundaries and reproducibility

    There are three document inputs and three assigned repetitions per configuration, not additional independent document families. A transport supplement is a separate configuration, not a replacement for original failed assignments. The 36 private-to-prompt test situations contain 132 component decisions per model repetition. Labels were prepared by an assistant before collection and require independent human adjudication. No confidence interval or quality ordering is inferred from these observations.

    Tasks cover a defined process within each source. Full semantic coverage of every requirement in the 200 pages has not been measured. Provider defaults for temperature and seed are not controlled by the MCP interface. Exact tool arguments and returned tool envelopes are retained; original HTTP response bytes are unavailable.

    Costs and authorised budget

    Reported charges include whatever input, output, reasoning and cache usage the serving provider billed. Native provider counts and router-reported counts can use different tokenisers. Reasoning and cache counters may overlap the reported totals; they must not be added again. A reported cache adjustment can be negative and is not interpreted as measured savings. Token subcategories are displayed when returned; missing accounting is not replaced by zero. Source acquisition and deterministic local processing have no billed model calls. The USD 40 ceiling applies cumulatively, including preceding tests and unresolved-cost reserves.
